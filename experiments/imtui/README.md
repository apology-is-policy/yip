# Switchboard development launcher

The branch default is `yip switchboard`. Use `make build` in the repository root and run `./yip switchboard --check` for the headless interaction checks. The accepted renderer is in `cmd/switchboard` and its C++ sources are in `third_party/imtui`. The development launcher still accepts `--demo` and `--check`.

See the Switchboard section in the repository README for controls and enrollment.
